# Synthetic Student Performance Analysis

A small, reproducible R project that demonstrates how to import, inspect, summarize, and
visualize a synthetic student-performance dataset. The project is designed as an example
of clear documentation and reproducible analysis; it does not use real student records.

## Overview

The project explores the relationship between study hours and assessment scores using
synthetic data generated inside R. It demonstrates a basic data-analysis workflow:

1. Generate a reproducible synthetic dataset.
2. Inspect the data structure and check for missing values.
3. Calculate descriptive summaries.
4. Create a scatter plot of study hours and scores.
5. Save the generated dataset and plot to an output folder.

Because the data are synthetic, the results are for learning and demonstration only.
They should not be interpreted as evidence about actual students.

## Requirements

- R (version 4.0.0 or later recommended)
- RStudio or another R environment
- `ggplot2` package

The script uses base R for data generation, inspection, and summary calculations.
`ggplot2` is used to create the visualization.

## Installation

1. Install R from [CRAN](https://cran.r-project.org/).
2. Optionally install RStudio from [Posit](https://posit.co/download/rstudio-desktop/).
3. Open the project folder in RStudio.
4. Install the required package by running:

```r
install.packages("ggplot2")
```

## Example Usage

Run the complete analysis from the R console:

```r
source("analysis.R")
```

The script creates an `output` directory (if it does not already exist), writes the
synthetic dataset to a CSV file, and saves a scatter plot as a PNG file. It also prints
the dataset structure, missing-value counts, and descriptive summaries to the console.

## Data Description

The dataset is generated by the script and contains 30 synthetic observations.

| Variable | Description | Type |
|---|---|---|
| `student_id` | Synthetic record identifier | Integer |
| `study_hours` | Simulated hours spent studying | Numeric |
| `score` | Simulated assessment score, from 0 to 100 | Numeric |
| `attendance_rate` | Simulated attendance percentage | Numeric |

No external or personal data files are required.

## Expected Outputs

After running `analysis.R`, the `output/` directory should contain:

- `synthetic_student_data.csv` — the generated synthetic dataset.
- `study_hours_vs_score.png` — a scatter plot showing study hours and assessment scores.

The script also prints summary information to the R console. Actual values should be
taken from a local run of the script rather than assumed from this documentation.

## Reproducibility

A fixed random seed is set in the script so that the synthetic dataset can be regenerated
consistently in the same R environment. The script creates its output folder automatically.
